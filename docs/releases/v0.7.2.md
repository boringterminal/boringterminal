## Sharper text rendering

- Fixed extra smoothing caused by glyph texture sampling and fractional text
  placement. Font bitmaps now align to backing pixels at 1× and 2× scale.
- Fixed stale rendering scale when moving a window between displays with
  different backing scales. Glyph atlases and terminal pixel dimensions now
  update with the window.
- Preserved font zoom and the continuous edges of box-drawing characters.

Automated pixel comparisons cover 1× → 2× → 1× transitions. Confirmation on
the displays where users reported blur remains pending.
