## Text zoom feedback

- Bigger Text, Smaller Text, and Actual Size now show a brief native hint with
  the zoom percentage and font size, such as **108% · 14 pt**.
- Repeated adjustments refresh the hint. **⌘0** confirms the configured size
  at **100%**, including when already at the default.
- The hint dismisses after 1.2 seconds, keeps keyboard focus in place, and
  lets mouse clicks pass through to the terminal.

## Title-bar layout

- Restored the sidebar toggle and new-session button to the left, beside the
  traffic lights, while preserving AppKit’s title-overlap protection.

Native UI validation covered zoom adjustments and reset, timer refresh and
dismissal, focus, click-through, narrow windows, and title-bar placement.
