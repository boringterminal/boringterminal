First launch

Releases are not yet notarized, so Gatekeeper refuses a plain double-click the first time. Any one of these works, once:

  • macOS 13 and 14: Control-click the app in Finder, choose Open, then confirm.
  • macOS 15 and later: double-click once and dismiss the warning, then open System Settings › Privacy & Security and click Open Anyway.
  • From a terminal: 
    xattr -dr com.apple.quarantine "/Applications/Boring Terminal.app"

More detail in the install docs.

Features

Persistent sessions
Closing the window does not end a long-running agent, shell, or build. Open the app again and the session is where you left it.
Attention routing
Sessions that need you are marked in the sidebar, driven by standard escape sequences, so it works with any agent.
Session sidebar
Every open session in one vertical list. No tabs to lose, no panes to manage.
Split sessions
Two related sessions side by side. One pair, nothing to configure.
Terminal graphics
Images and video rendered inline alongside text, via the Kitty graphics protocol.
Mac-native, Metal-only
Real IME input, dead keys, emoji, drag-and-drop paths. GPU-rendered with Metal. No portability layer.

Why boring

Built in the agent era, not only for it. Whether you're running ten agents or one shell, the terminal's job is the same: stay out of the way and tell you when something needs you. Every feature either passes one test or stays out: “does it help someone run ten agents and know which one needs them?” Read the philosophy.
