title: Keyboard shortcuts
description: Every shortcut in Boring Terminal.
---

This reference is also available in the app under **Help › Keyboard
Shortcuts** (<kbd>⌘?</kbd>).

## Sessions

| Shortcut | Action |
|---|---|
| <kbd>⌘T</kbd> | New session |
| <kbd>⌘D</kbd> | New session beside the current one (creates a pair) |
| <kbd>⌘W</kbd> | Close the focused session |
| <kbd>⌘⇧[</kbd> / <kbd>⌘⇧]</kbd> | Previous / next session |
| <kbd>⌘1</kbd> … <kbd>⌘9</kbd> | Switch to session by position |
| hold <kbd>⌘</kbd> | Show session number badges in the sidebar |
| <kbd>⌥⌘↑</kbd> / <kbd>⌥⌘↓</kbd> | Focus previous / next sidebar row |
| <kbd>⇧⌥⌘↑</kbd> / <kbd>⇧⌥⌘↓</kbd> | Move sidebar row up / down |

## Pairs

| Shortcut | Action |
|---|---|
| <kbd>⌥⌘←</kbd> / <kbd>⌥⌘→</kbd> | Focus left / right pane |
| <kbd>⇧⌥⌘←</kbd> / <kbd>⇧⌥⌘→</kbd> | Move pane left / right |
| <kbd>⇧⌘↩</kbd> | Zoom the focused pane (again to restore both) |

Pair with previous/next session, separate sessions, and swap sides are in the
**Session** menu and each row's context menu.

## Terminal

| Shortcut | Action |
|---|---|
| <kbd>⌘C</kbd> | Copy selection |
| <kbd>⌘V</kbd> | Paste |
| <kbd>⌘K</kbd> | Clear to start |
| <kbd>⌘F</kbd> | Find in session |
| <kbd>⌘G</kbd> / <kbd>⇧⌘G</kbd> | Next / previous match |

## Application

| Shortcut | Action |
|---|---|
| <kbd>⌘B</kbd> | Toggle the session bar |
| <kbd>⌘+</kbd> / <kbd>⌘−</kbd> | Increase / decrease text size |
| <kbd>⌘0</kbd> | Reset text size |
| <kbd>⌘,</kbd> | Open configuration |
| <kbd>⌘?</kbd> | Keyboard shortcuts |
| <kbd>⌘Q</kbd> | Quit (sessions keep running) |
