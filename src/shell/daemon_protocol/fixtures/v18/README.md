# Attach dialect 18

Frozen from public release `v0.5.0`, commit
`981949eadee6631abcf880bd4ad23a2aacc1442e`.

The snapshot fixtures are complete `BTD1` frames with the four pointer values
encoded in the high two mode bits. They are intentionally hand-auditable 2x1
blank snapshots and must not be regenerated through the current v19 codec.
Replace this directory only through RFC 0019's compatibility-window rotation.
